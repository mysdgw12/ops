# 行动档案 OPERATIONS

自用的事件记录 + 重要度分级 + 到点提醒工具。明日方舟风格界面，纯本地运行，数据不上传任何服务器。

- **版本**：v1.0.0
- **适用**：Android / HyperOS 手机（红米 K100 等），Chrome / Edge 浏览器
- **体积**：整个应用 < 120 KB，可离线使用

---

## 1. 能做什么

| 功能 | 说明 |
| --- | --- |
| 事件记录 | 标题、备注、截止时间、标签、子任务清单 |
| 重要程度 | 四级：紧急 / 高 / 中 / 低（灰·蓝·黄·红四色条） |
| 到点提醒 | 应用打开时：顶部横幅 + 提示音 + 震动通知（授权后） |
| 系统日历提醒 | 一键导出 `.ics`，导入小米日历后由系统闹钟提醒，杀后台也准点 |
| 重复任务 | 每天 / 每个工作日 / 每周 / 每月；勾选完成后自动生成下一次 |
| 快速添加 | 一句话：`明天9点 交报告 !高 #工作 每周` |
| 视图 | 档案（全部/今天/本周/逾期/已完成）、日程时间线、统计、设置 |
| 统计 | 本周完成数、待处理、逾期、连续天数、执行率环形图、8 周热力图、标签分布 |
| 搜索筛选 | 关键词搜索 + 标签点选筛选 |
| 回收站 | 删除可撤销，误删能找回 |
| 数据备份 | 导出 / 导入 JSON，换机不丢 |
| 离线 | 走 PWA 安装后完全离线，断网也能用 |

## 2. 三种打开方式（先选一种）

| 方式 | 能安装到主屏幕 | 系统通知 | 离线 | 难度 |
| --- | --- | --- | --- | --- |
| **A. 托管到静态网站**（推荐） | ✅ | ✅ | ✅ | 需要账号，一次性 |
| **B. 单个 HTML 拷到手机** | ❌（可用"添加到主屏幕"当书签） | ⚠️ 受浏览器限制 | ✅ | 最简单 |
| **C. 电脑局域网服务器** | ❌ | ❌ | ⚠️ 需电脑常开 | 仅试玩 |

> 关键原因：浏览器只允许 `https://` 页面使用"安装应用"和"系统通知"。本地 `file://` 打开能正常记录和提醒（应用开着的时候），但装不成真 APP。

### 方式 A：托管（想要完整 APP 体验就选这个）

任选一个免费静态托管，把整个 `todo-pwa` 文件夹传上去，得到一个 `https://` 地址：

- **GitHub Pages**：新建仓库 → 上传 `todo-pwa` 里的文件（`index.html`、`app.css`、`app.js`、`sw.js`、`manifest.webmanifest`、`icons/`）→ Settings → Pages → Branch 选 `main` / root → 等 1 分钟，得到 `https://用户名.github.io/仓库名/`
- **Gitee Pages**：同上（国内访问更快，需实名）
- **Cloudflare Pages / Vercel / Netlify**：拖拽文件夹即可，几分钟出地址

拿到地址后，在手机 Chrome 打开 → 菜单 ⋮ → **安装应用 / 添加到主屏幕**。

### 方式 B：单个文件拷到手机

把 `dist/行动档案-单文件版.html` 传到手机（数据线 / 微信文件传输 / 网盘都行），用 Chrome 打开。

- 记录、提醒、统计、导出全部可用
- 数据存在浏览器本地，**换浏览器或清理数据会丢**，请定期导出 JSON 备份
- Chrome 菜单里"添加到主屏幕"会生成一个快捷方式（本质是书签）

### 方式 C：电脑上试玩

在 `todo-pwa` 目录执行（需要 Python）：

```powershell
python -m http.server 8080
```

手机和电脑连同一个 Wi-Fi，手机浏览器访问 `http://电脑IP:8080`。

## 3. 装到主屏幕之后

1. 打开应用 → 底栏 **设置**
2. **系统通知** 开关打开 → 浏览器弹窗点"允许"
3. **提示音** 保持开启（提醒时会"嘀"两声）
4. 建议把应用加入电池白名单，避免 HyperOS 杀后台导致提醒延迟：
   `设置 → 应用设置 → 应用管理 → 行动档案 → 省电策略 → 无限制`

## 4. 让提醒绝对准时（重要）

浏览器在**应用完全关闭时无法保证准点响铃**。稳妥做法是把带时间的事件同步到系统日历：

1. 设置页 → **导出到系统日历（.ics）**
2. 手机会下载一个 `行动档案-日历-日期.ics`
3. 用**小米日历**打开该文件（文件管理里点一下，选"日历"）
4. 导入后，每个事件都带一个"开始时提醒"的闹钟，由系统负责准点响铃

重复任务导出时会带上重复规则（每天/每周/每月），日历里自动展开。

## 5. 快速添加语法

在档案页顶部输入框敲一句话，回车即可：

```
明天9点 交报告 !高 #工作
周五下午3点 开会 #项目
每月15号 交房租
11月25日 体检 !急
今天晚上8点半 跑步 每天
买菜                      ← 没时间也能记
```

| 写法 | 含义 |
| --- | --- |
| `!急` `!高` `!中` `!低`（或 `!1`~`!4`） | 重要度：紧急 / 高 / 中 / 低 |
| `#工作` `#生活` | 标签，可多个 |
| `今天` `明天` `后天` `大后天` | 日期 |
| `周五` `下周一` `周三` | 本周/下周的那天 |
| `11月25日` `11-25` `15号` | 具体日期 |
| `9点` `9:30` `下午3点半` `晚上8点` | 时间（不写日期默认今天，已过则算明天） |
| `每天` `工作日` `每周` `每月` | 重复 |

解析完的标题会去掉这些标记。也可以点右上角 **＋** 手动填写全部字段。

## 6. 备份与换机

- **导出备份（JSON）**：设置页 → 导出 → 得到一个包含全部事件和设置的 `.json`
- **导入备份（合并）**：保留现有数据，同 ID 事件以备份为准（日常恢复用这个）
- **导入备份（覆盖）**：清空后导入（换新手机时用）

建议每周导出一次，存到网盘或电脑。

## 7. 界面说明

- **档案**：所有待处理事件，按 逾期 / 今天 / 本周 / 以后 / 未设时间 分组；左色条即重要度
- **日程**：今天的时间线（按时间排列）+ 逾期 + 未设时间的
- **统计**：本周完成、连续天数、执行率环形、8 周热力图、标签分布
- **设置**：通知、提示音、日历导出、备份、回收站、安装说明

交互小细节：
- 点左侧方框 = 标记完成（会盖一个 `MISSION COMPLETE` 章，重复任务会自动排下一次）
- 点卡片其他位置 = 编辑
- 逾期事件：红色边框 + 黄色警示三角 + 红色倒计时
- 搜索框右侧的 × 可一键清空搜索

首次打开会带 5 条示例事件，用来展示各种状态，直接删除即可。

## 8. 已知限制（如实说明）

1. **应用关闭后不会自动响铃** —— 浏览器限制，用 `.ics` 导入系统日历解决
2. 系统通知需要 `https://` 环境；`file://` 打开时只有应用内横幅和提示音
3. 单文件版的数据存在浏览器里，清理浏览器数据会丢失，务必导出 JSON 备份
4. 没有云同步、没有多人协作、不做账号（自用不需要，也就不需要服务器）
5. 一小时内的提醒精度约 15 秒（后台定时器节流）

## 9. 文件结构

```
todo-pwa/
├── index.html              入口页面（结构）
├── app.css                 视觉系统（明日方舟风格）
├── app.js                  全部逻辑（数据/渲染/提醒/导出）
├── manifest.webmanifest    PWA 清单（安装信息）
├── sw.js                   离线缓存
├── icons/                  应用图标
├── dist/行动档案-单文件版.html   单文件版（可直接拷到手机）
└── tools/                  开发辅助
    ├── make_icons.py       生成图标
    ├── build-single.mjs    打包单文件版
    └── cdp.mjs             无头浏览器自动化截图/自测
```

## 10. 调试参数

在地址后加参数可直达状态，方便排查：

| 参数 | 作用 |
| --- | --- |
| `?nosplash=1` | 跳过启动动画 |
| `?view=stats` | 直接打开统计页（archive / schedule / stats / settings） |
| `?open=1` | 启动即打开新建事件面板 |
| `?debug=1` | 暴露 `window.__ops`（数据、解析、导出函数），供自测 |

---

数据只保存在你自己的手机上。想改配色/字号，改 `app.css` 顶部的 `:root` 变量即可。
